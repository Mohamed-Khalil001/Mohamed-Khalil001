My work bridges rigorous astrodynamics (Clohessy–Wiltshire, Schweighart–Sedwick $J_2$, 8th-order Dormand–Prince `DOP853` Cowell numerical propagation, and 2D B-plane covariance quadrature) with production-grade machine learning and operational decision-support systems.

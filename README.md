## 🚀 Featured Aerospace & AI Projects

### 🛰️ ORBITAL-AI — Spacecraft Collision Avoidance

[**View Repository**](https://github.com/Mohamed-Khalil001/orbital-esa-collision-avoidance) · [**Launch Live Application**](https://orbital-esa-collision-avoidance-3ewp7cecpuqb3kh6kmmbse.streamlit.app/)

A machine-learning and astrodynamics project focused on spacecraft conjunction assessment and collision-avoidance decision support, based on the ESA Kelvins Spacecraft Collision Avoidance Challenge.

**Key components:**
- Two-stage LightGBM classification architecture and conditional regression.
- Physics-guided feature engineering and risk assessment.
- Orbital propagation using Clohessy–Wiltshire and Schweighart–Sedwick models.
- Numerical orbit propagation using DOP853 Cowell integration.
- Interactive visualization and operational interfaces.

**Reported project results:**
- F2 score: `0.76923`
- ESA loss: `0.63548`
- Cross-validation and simulator validation workflows.

**Technology:** Python · LightGBM · FastAPI · Streamlit · Three.js · Astrodynamics
